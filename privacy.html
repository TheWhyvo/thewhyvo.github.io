Privacy Policy

Effective date: October 20, 2026

This policy describes how the "ytauto" application (the Whyvo uploader) handles data. ytauto is a private tool used only by the owner of the Whyvo YouTube channel to publish the channel's own videos. It is not offered to the public, and it does not collect data from viewers or other users.

Google and YouTube data the app accesses

When the channel owner signs in with Google, ytauto requests permission to:

  • upload videos and set thumbnails on the owner's YouTube channel (scope youtube.upload);
  • upload caption (subtitle) files for those videos (scope youtube.force-ssl).

ytauto uses these permissions only to upload the channel's own videos, thumbnails, captions, titles, descriptions and tags. It does not read, analyze or store other YouTube data, comments, subscriber information or analytics.

How data is stored

The sign-in token issued by Google is stored only on the channel owner's own computer. ytauto has no server and does not send this token or any other data to the developer or to any third party, except to Google's YouTube Data API to perform the uploads described above.

Sharing

No data is sold, shared, or transferred to third parties.

YouTube API Services

ytauto uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the token file from the computer also removes ytauto's access.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
